# AKADEX Product Requirements Document (PRD)

## Product Overview

AKADEX is a web-based academic productivity platform designed to help students organize coursework, manage tasks, track study sessions, and improve productivity through an integrated academic workspace.

The platform combines task management, subject organization, productivity tracking, and focus tools into a single application tailored for students.

---

## Problem Statement

Students often rely on multiple applications to manage their academic responsibilities, including calendars, to-do lists, note-taking tools, and study timers. This fragmented workflow leads to context switching, reduced productivity, missed deadlines, and poor organization.

AKADEX aims to centralize these functions into one cohesive platform.

---

## Product Vision

To become the all-in-one academic productivity platform that empowers students to organize, focus, and achieve their academic goals.

## User Stories

### Authentication

As a student, I want to create an account so that my academic data is securely stored.

### Tasks

As a student, I want to create and manage tasks so that I can keep track of assignments and deadlines.

### Subjects

As a student, I want to organize tasks by subject so that I can manage coursework efficiently.

### Pomodoro

As a student, I want to track focused study sessions so that I can improve productivity.

### Analytics

As a student, I want to see productivity statistics so that I can evaluate my study habits.

## Success Metrics

### MVP Success Criteria

* Users can register and log in.
* Users can create and manage subjects.
* Users can create and manage tasks.
* Users can use the Pomodoro timer.
* User data persists correctly.
* Productivity statistics are generated correctly.

### Technical Success Criteria

* Application deployed successfully.
* Responsive UI on desktop and mobile.
* Secure authentication.
* Database integrity maintained.
* Average page load under 2 seconds.
