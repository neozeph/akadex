# ACADEX Sprint Plan

## Sprint Methodology

Framework: Agile Scrum

Sprint Length: 1 Week

---

# Sprint 1 – Project Foundation

Goal:
Set up the development environment and authentication system.

Tasks:

* Initialize Next.js Project
* Configure Tailwind CSS
* Configure ShadCN UI
* Configure Prisma
* Configure PostgreSQL
* Configure Auth.js
* Create Database Schema
* Create Authentication Pages

Deliverable:

* User Registration
* User Login
* Protected Dashboard Access

---

# Sprint 2 – Subject Management

Goal:
Build subject organization features.

Tasks:

* Create Subject Model
* Subject CRUD APIs
* Subject UI Components
* Subject Dashboard Cards

Deliverable:

* Full Subject Management

---

# Sprint 3 – Task Management

Goal:
Build task tracking system.

Tasks:

* Create Task Model
* Task CRUD APIs
* Task Filters
* Task Priorities
* Task Status Updates

Deliverable:

* Full Task Management

---

# Sprint 4 – Pomodoro System

Goal:
Implement productivity timer.

Tasks:

* Timer Component
* Session Tracking
* Timer Settings
* Session History

Deliverable:

* Functional Pomodoro Module

---

# Sprint 5 – Analytics Dashboard

Goal:
Provide productivity insights.

Tasks:

* Productivity Metrics
* Weekly Statistics
* Focus Tracking
* Charts and Reports

Deliverable:

* Analytics Dashboard

---
